# Roadmap V1 (2026-09-22)

Specs : `specs/2026-09-22-cible-v1.md`, `specs/2026-09-22-agent-ia.md`.

Quatre lots dans l'ordre. Chaque lot se livre en plusieurs PR courtes, en merge
commit. Le plan détaillé d'un lot s'écrit à son démarrage, pas avant : écrits trop
tôt, les plans du 2026-09-04 étaient périmés avant d'être exécutés.

## Porte avant ouverture au public

Rien n'est ouvert à des élèves avant :
- art. 50(1) traité dans le prompt et dans l'interface ;
- détresse et modération mesurées par le harnais ;
- endpoint UE et ZDR actifs ;
- double consentement sous 15 ans ;
- avis d'un conseil sur l'art. 50(2) et la frontière GPL de `pawnote` ;
- pages légales alignées sur l'hébergement réel.

## Hors roadmap, délibérément

- Retour d'un RAG vectoriel : aucun gain d'exactitude démontré (Adenuga 2026).
  L'ancrage passera par des données structurées si le lot 2 en montre le besoin.
- Fournisseur hors Mistral, auto-hébergement de poids, fine-tuning.
- Application native : réécrite après la V1 web, avec sa propre UI.
- TypeScript 7 : bloqué tant que `typescript-eslint` exige `typescript <6.1.0`
  (vérifié le 2026-09-22 sur `typescript-eslint@8.70.0`).
