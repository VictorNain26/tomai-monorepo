### Tâche D.3 — Frontières de reset en Europe/Paris via `@date-fns/tz`

Bugs vérifiés dans `src/services/quota/quota-config.ts` :
- `needsWeeklyReset` (l. 158-179) : `thisMonday.setDate(…)` en heure locale du process puis `setUTCHours(0)` → lundi 00:00 **UTC**. Le lundi 21/09/2026 à 00:30 Paris, il renvoie « pas de reset » pour un compteur remis le dimanche ; le lundi midi, il en redemande un pour un compteur déjà remis à 00:30 Paris.
- `needsDailyReset` (l. 115-139) : l'offset Paris est dérivé de l'heure courante et appliqué au jour entier. Le 25/10/2026 à 09:30 CET (après le passage à l'heure d'hiver), la frontière de la veille est calculée à 09:00Z au lieu de 08:00Z : un compteur remis à 10:30 CEST la veille est remis une seconde fois.
- `getDailyResetTime` (l. 141-156) : heures entières seulement, la branche `< 1 → min` est morte ; affiche « 1h » à 09:59 et « 9h » à 01:30 le jour du passage à l'heure d'été (7 h 30 réelles).
- `getUsageStats` (`quota-functions.ts:270`) renvoie `tokensUsedThisWeek` brut, sans appliquer `needsWeeklyReset` : le compteur de la semaine passée reste affiché jusqu'au prochain message.

Bibliothèque : `date-fns` 4 + `@date-fns/tz` (Temporal absent de Bun 1.3.14 : `typeof globalThis.Temporal === 'undefined'`, vérifié). API vérifiée dans les `.d.ts` de `date-fns@4.4.0` et `@date-fns/tz@1.5.0` installés en bac à sable :
- `tz(timeZone: string): (value) => TZDate` — `@date-fns/tz/tz/index.d.ts:11`
- option `in?: ContextFn` sur `startOfDay`, `setHours`, `addDays`, `startOfWeek` — `date-fns/types.d.ts:292-298` (`ContextOptions`)
- `startOfWeek(date, { weekStartsOn: 1, in })` — `date-fns/startOfWeek.d.ts:10-13`
- `differenceInMinutes(later, earlier, { roundingMethod: 'ceil' })` — `date-fns/differenceInMinutes.d.ts:5`, `types.d.ts:220-223`
- Doc : https://github.com/date-fns/tz (section « Context »). Prototype exécuté sur les dates des tests ci-dessous : résultats identiques aux valeurs attendues.

`needsMonthlyReset` (comparaison de `YYYY-MM` formatés en Europe/Paris) est correcte : non touchée.

            _error: err instanceof Error ? err.message : String(err),
            severity: 'high' as const,
          });
        }
      }

      logger.info('Shutdown completed', { operation: 'server:shutdown' });

  ```ts
  "use server";

  import { z } from "zod";
  import { SERVER_URL } from "@/lib/urls";

  const EMAIL_REGEX = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

  const waitlistSuccessSchema = z.object({
    success: z.literal(true),
    alreadyExists: z.boolean(),
  });

  export type JoinWaitlistResult =
    | { success: true; alreadyExists: boolean }
    | { success: false; error: string };

  export async function joinWaitlist(email: string, source: string): Promise<JoinWaitlistResult> {
    if (!email || !EMAIL_REGEX.test(email)) {
      return { success: false, error: "Adresse email invalide" };
    }

    let res: Response;
    try {
      res = await fetch(`${SERVER_URL}/api/waitlist`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ email, source }),
      });
    } catch {
      return { success: false, error: "Erreur de connexion au serveur" };
    }

    if (res.status === 400) {
      return { success: false, error: "Adresse email invalide" };
    }
    if (res.status === 429) {
      return { success: false, error: "Trop de tentatives, réessayez dans une minute." };
    }
    if (!res.ok) {
      return { success: false, error: "Inscription impossible pour le moment, réessayez plus tard." };
    }

    const parsed = waitlistSuccessSchema.safeParse(await res.json().catch(() => null));
    if (!parsed.success) {
      return { success: false, error: "Inscription impossible pour le moment, réessayez plus tard." };
    }
    return parsed.data;
  }
  ```
